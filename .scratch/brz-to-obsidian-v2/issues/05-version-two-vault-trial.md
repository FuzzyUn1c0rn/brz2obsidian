Include thought types and assignments, inherited/overridden appearance where verified, definition content/resources, and the additional concepts accepted for version 2. Keep private prototypes and native screenshots under ignored `brz/`. Link the prototype and a short review record from this ticket. Distinguish what native Obsidian actually demonstrated from what the user accepted. This is a decision aid, not a production converter or proof that the full new archive already converts.

If coverage or representation tickets surface new prerequisites, wire them before beginning the trial. Resolve through the user's live verdict and record any remaining limits.

## Answer

The native prototype supports the proposed category/template/property/Base/dashboard representation. The user reviewed it in Obsidian, said it looks good overall and that they are quite happy with this version, and requested Icon as the first table column followed by Note. In subsequent review they explicitly removed the decorative Appearance display and said the rest looks good. The current presentation keeps Icon then Note, omits Appearance from table/gallery views, and retains other settings. It is applied across the category and future-category Bases, with the overview also placing Icon first, and captured in the disposable builder for future trial generation.

The Book symbol is a real copied PNG. Its property stores an image-file link; the member template leaves `icon` empty and supplies `appearance_category`, so dashboard icons inherit from the linked category unless the note provides its own image override.

The [trial record](../research/vault-trial.md) distinguishes demonstrated native behavior from the live presentation verdict. The three exposed maintenance choices were carried to [Choose maintenance adaptations exposed by the native vault trial](12-native-maintenance-adaptations.md) and subsequently accepted through a separate live grilling round. Specification handoff is now unblocked. Full converter delivery, preservation/regression checks and final converted-vault acceptance remain later gates.
