- [ ] A complete mixed synthetic conversion combines forgotten exclusion, exact supplied Markdown, multi-image absent ordinary notes, missing type body/icon with included/overridden members, multiple-parent category hierarchy, Home/tags/dates/collision naming, PDFs/ZIP/generic files/external URLs and reviewed video timing. - [ ] Public library/default wiring/dependency injection, console/module text/JSON and strict schema/profile versions agree. Reject incompatible combinations and inconsistent owner/asset/finding joins. Inspection remains read-only with measured source facts/planned obligations and no publication counts/receipt; conversion retains clean/warnings/refused/failed and exits 0/2/1/1.
- [ ] Conversion prepares afresh and verifies the complete new artifact plan before safe fresh-destination publication. Source fingerprints/scoped digest/policy bind analysis, plan, generated presentations, manifests and durable receipt. Missing bytes and generated images cannot inflate original-byte or authored-reference conservation credit.
- [ ] Extend existing real stream/write/copy and staging-deletion/truncation/same-length-corruption tests to new artifacts. Exercise source mutation, unsafe paths/Windows junctions, rename/rmdir races and teardown/post-commit failures at highest practical existing boundaries. Caller before/after inventories/hashes and owned cleanup prove no caller deletion or partial accepted output.
- [ ] After actual verified publication, preserve/report durable receipt even if a later stage fails; do not claim no publication. Report only available measurements and null unknown counts on refusal/failure, without exclusion leakage or invented success facts.
- [ ] Exact/repeat/root-record and ZIP-order permutations keep selections, paths, body edits, image ordering, findings/affected-member order and logical output deterministic. Differences are restricted to documented input/snapshot provenance, raw evidence ordering and explicit clock/run/bookmark metadata.
- [ ] The independent source-free checker accepts actual generated embeds/neutral properties, detects missing images/real convention defects, retains schema 1 unless shape changes, and preserves caller inventory/bytes on success/failure. It neither trusts a historical receipt to prove current content nor becomes a source-gap/preservation oracle.
- [ ] Current non-UUID alternate source and inward import barriers prove source-neutral reuse. No BRZ numeric role/ForgottenDateTime parsing enters generic planning. Existing v1/v2 cumulative public behavior stays green.
- [ ] Update library/CLI/schema/coverage/checker/publication documentation and run relevant package/documented-example smoke against 0.3.0. The delivered distribution contains runtime material only; do not publish private fixtures, vaults or screenshots. Record integration proof and remaining full-input/native/user gates.
