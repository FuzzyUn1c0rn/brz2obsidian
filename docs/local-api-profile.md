## Common predicates

`B` is the verified requested Brain UUID: lowercase canonical hyphenated UUID, nonzero. UUID records must decode to that canonical identity; no trimming, prefix comparison or foreign ownership is allowed. `T` and `L` are authoritative GET thought/link metadata, never search stubs. Each fetched identity matches its requested identity and Brain. Missing required keys, wrong scalar types (including booleans as integers), unknown enum declarations and conflicting repeated observations refuse. Explicit null is distinguishable from absent. Duplicate identical identity/fields retain observation provenance and produce one normalized fact; contradictory copies refuse rather than choosing the latest response.

`Included(T)` requires qualified role, explicit public access, qualified non-forgotten status, and ownership B. Required Home must itself satisfy the ordinary included predicate. A known excluded forgotten/system endpoint removes its associations from output under the explicit exclusion predicate. A private endpoint refuses without retaining its content. Included unresolved endpoints refuse. Known excluded endpoints remove their associations before normalization; an unresolved endpoint is not an exclusion. System/private/forgotten status is never inferred from an unavailable GET, a name, an archive-only record, or an unexplained numeric meaning.

A valid non-sentinel timestamp is a string matching `YYYY-MM-DDTHH:MM:SS`, optionally followed by a dot and one to seven decimal digits, optionally followed by `Z` or `+HH:MM`/`-HH:MM`. Calendar/time/offset components must be valid; seconds00-59, offsets at most14:00. Year0001 refuses except the exact no-note wrapper predicate. No whitespace trimming, guessed timezone or alternate date-only syntax is accepted. Optional suffix does not change calendar component mapping. This narrow grammar is the qualification target for source dates; additional source formats need review.

For the narrow file rules, `basename` means a nonempty location containing no slash, backslash, colon, percent sign, C0/DEL control, leading/trailing whitespace, or `.`/`..` value. Treat it literally without percent/path decoding. Filename extension is the final dot suffix, compared ASCII case-insensitively. File `name` must be explicitly null or a nonempty string; it is a display label, preserved verbatim, and does not classify the file. `location` supplies the original filename.

Every produced fact points to scoped safe evidence. No absent payload gets empty fabricated bytes. Measurements mean complete successful bounded reads with actual byte length and SHA-256, not `dataLength`. Operational failures and malformed replies remain typed failures/refusals, with safe request identity and classified outcome, not arbitrary body text.

## Exact zero-tag matcher

Only a failed **GET** `/api/thoughts/{B}/tags`, HTTP400, is eligible. Read within a declared bound and decode strict UTF-8. Remove leading/trailing whitespace only: U+0009-U+000D, U+001C-U+0020, U+0085, U+00A0, U+1680, U+2000-U+200A, U+2028-U+2029, U+202F, U+205F and U+3000 (the assessed Python `str.strip()` set); do not case-fold, collapse internal whitespace, URL-decode, substitute aliases or parse as JSON. The remaining string equals exactly `Could not retrieve list of Tags for brain ` followed by **B**, the already verified requested canonical Brain UUID. A BOM is not whitespace and refuses. The retained filename extension has no bearing on plaintext interpretation.

Require explicit integer starting and ending `tags=0` from validated same-Brain statistics and no authoritative tag metadata, graph tag, classification reference or inventory result indicating any tag. Missing counts, nonzero counts, a discovered tag or disagreement refuses. Retain the HTTP400 classification and corroboration. Never save arbitrary error bodies or claim the request succeeded. The bounds and safe request/outcome transport are implementation obligations in later tickets.

Independent negatives must alter one factor at a time: POST/other endpoint/status; other UUID; noncanonical UUID; changed capitalization/punctuation; leading BOM; internal whitespace; prefix/suffix non-whitespace; JSON quoting; invalid UTF-8; absent/nonzero starting or ending counts; contradictory tag metadata or graph/reference. Authentication/permission failures cannot use this exception.
